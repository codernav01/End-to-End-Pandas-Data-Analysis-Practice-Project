# Pandas Data Analysis Foundations

## Purpose

A hands-on employee-data project used to practise the core Pandas workflow: inspection, cleaning, transformation, filtering, feature engineering, aggregation, and exploratory analysis.

## Skills Practised

- loading and inspecting tabular data
- data-type review
- missing-value handling
- categorical cleaning
- outlier detection using IQR
- filtering and query-based selection
- `apply`, `map`, and `replace`
- derived columns and binning
- `groupby`, sorting, and ranking
- department/city-level analysis

## Dataset

The repository uses `employee_pandas_practice.csv`, a structured employee dataset containing fields such as age, salary, department, experience, rating, and project information.
